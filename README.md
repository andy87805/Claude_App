# 常用剪貼簿

把常用的文字片段（回覆範本、地址、指令、連結…）分類存起來，**點一下就複製**。

- 單一 HTML 檔（`ClipBoard.html`），用 Edge／Chrome 直接打開就能用
- **完全不需要網路**、不用安裝、不需要管理員權限
- 資料只存在這台電腦的瀏覽器裡，可以設定自動備份到 OneDrive

## 檔案

| 檔案 | 說明 |
|---|---|
| `ClipBoard.html` | 主程式，雙擊用瀏覽器開啟 |
| `ClipBoard.ico` | 桌面捷徑用的圖示（可省略，頁面裡也能下載） |

## 開始使用

1. 把 `ClipBoard.html`（和 `ClipBoard.ico`）放在固定的資料夾，例如 OneDrive 裡，之後不要移動
2. 用 Edge 打開 `ClipBoard.html`
3. 按左側「設定自動備份」，選一個資料夾存放備份
4. 按左下角「用快捷鍵開啟」，照步驟建立桌面捷徑和快速鍵（例如 `Ctrl`+`Alt`+`V`）

## 功能

- **點一下卡片就複製**，按鈕會變綠色「已複製」並跳出通知
- 分類：左側切換；可新增、改名、改顏色、刪除（刪除分類時內容會移到「未分類」，不會被刪掉）；把卡片**拖到左側分類**就能搬移
- 釘選常用內容到最前面；排序可選「自訂（拖曳卡片排序）／最常用／最近用」
- 搜尋標題、內容、分類名稱，按 `Enter` 直接複製第一筆
- 在頁面上直接按 `Ctrl/⌘ + V`，會把剪貼簿內容帶進「新增」視窗；重複的內容會提醒
- 變數：內容裡的 `{{date}}`、`{{time}}`、`{{weekday}}`（或 `{{日期}}`、`{{時間}}`、`{{星期}}`）會在複製時換成當下的日期、時間、星期
- 私密內容：卡片上用 •••• 遮住，複製時仍是原文
- **每行分開複製**（逐行模式）：多行內容的每一行都能單獨複製，點哪一行就複製哪一行，「複製」按鈕仍複製全部
  - 「姓名：王小明」這種「名稱：內容」格式只會複製冒號後面的「王小明」，方便填表；Shift＋點一下複製整行
  - 新增時如果每一行都是「名稱：內容」或連結，會自動開啟；卡片上的 ☰ 按鈕或 `L` 鍵可隨時切換
  - 超過 6 行可展開；私密內容會顯示名稱、遮住內容
- **連結**：網址、資料夾、檔案路徑（`C:\…`、`\\伺服器\…`、Mac 的 `/Users/…`）會變成可以點的連結；整則內容就是一個連結時，卡片上會多一顆「開啟」按鈕（或按 `O`）
  - 網址：在新分頁開啟
  - 資料夾、檔案：在瀏覽器新分頁開啟（資料夾會列出裡面的檔案）。網頁無法直接叫出檔案總管，所以複製路徑時會提示：**Win+R → 貼上 → Enter** 就能用檔案總管開資料夾，或用原本的程式開檔案（Mac：在 Finder 按 ⌘⇧G 貼上）
- 快捷鍵：`1`–`9` 複製第幾則、`/` 搜尋、`N` 新增、方向鍵在卡片間移動、`E` 編輯、`P` 釘選、`L` 逐行模式、`O` 開啟連結、`Del` 刪除（可復原）；逐行模式中按 `Tab` 進入各行、`↑` `↓` 移動、`Enter` 複製
- **自動備份**（Edge／Chrome）：按「設定自動備份」選一個資料夾（建議在 OneDrive 裡新增一個，例如「剪貼簿備份」），之後**只要內容有修改**就自動寫入備份，平常開啟不會讀取備份檔
  - 寫入 `clipboard-backup.json`（最新）和 `clipboard-backup-日期.json`（每日一份，保留最近 30 份，誤刪時可以找回前幾天的版本）
  - 只是複製（次數改變）不會觸發備份
  - 重新開啟瀏覽器後的第一次修改，瀏覽器會請你允許寫入一次（基於安全規定）；拒絕的話會顯示「允許並備份」按鈕
  - 選的資料夾裡已經有備份時，會先合併進來，不會直接覆蓋
  - 瀏覽器資料被清除時：按「匯入」選 `clipboard-backup.json` 就能還原
- 匯出／匯入：手動存成 JSON 檔；匯入會合併並略過重複內容（畫面上只有範例時，會直接換成匯入的內容）
- **用快捷鍵開啟**：按左下角「用快捷鍵開啟」，照步驟建立桌面捷徑，用 Edge 的應用程式模式開啟（沒有網址列，像獨立程式），並設定快速鍵（例如 `Ctrl`+`Alt`+`V`）。不需要安裝任何東西或管理員權限
- 圖示：分頁和 Edge 應用程式視窗會顯示剪貼簿圖示；桌面捷徑可在「內容 → 變更圖示」選 `ClipBoard.ico`（說明視窗裡也能直接下載）
- 注意：「私密內容」只是畫面上遮住，資料沒有加密，不建議存放密碼
- 支援淺色／深色模式與手機版面

## 更新版本

直接用新的 `ClipBoard.html` 覆蓋舊檔即可，**資料不會不見**：資料存在瀏覽器裡，不在 HTML 檔裡。
